# Inventory Management System

A command-line Inventory Management System developed in Python.

This project demonstrates fundamental software engineering concepts including CRUD operations, JSON data persistence, input validation, feature-based Git workflow, and version control using Git and GitHub.

---

# Features

- Add Product
- View Inventory
- Search Product by Code
- Update Product
- Delete Product
- Prevent Duplicate Product Codes
- Validate User Input
- Save Inventory to JSON
- Load Inventory from JSON
- Inventory Statistics

---

# Technologies

- Python 3
- JSON
- Git
- GitHub
- Command-Line Interface (CLI)

# How to Run

Clone the repository:

```bash
git clone https://github.com/sadafheidari/inventory-management-system.git
```

Move into the project folder:

```bash
cd inventory-management-system
```

Run the application:

```bash
python inventory_management_system.py
```

# Git Workflow

This project was developed using a feature-branch workflow.

Completed branches include:

- add-product
- search-product
- feature/delete-product
- feature/save-json
- feature/duplicate-code-check
- feature/input-validation
- feature/update-product
- feature/inventory-statistics

Each feature was developed, tested, committed, pushed to GitHub, and merged into the main branch independently.
